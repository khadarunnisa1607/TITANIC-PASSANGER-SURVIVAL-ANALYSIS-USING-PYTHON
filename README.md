# TITANIC-PASSANGER-SURVIVAL-ANALYSIS-USING-PYTHON
Exploratory data analysis of Titanic passenger demographics, fares, family size, and survival patterns using Python, Pandas, NumPy, Matplotlib, and Seaborn.


## Project Overview

This project performs exploratory data analysis on the Titanic passenger
dataset to identify patterns in passenger demographics, travel
characteristics, and survival outcomes.

## Objectives

- Analyze passenger demographics
- Examine passenger class and fare distribution
- Investigate survival patterns by gender and passenger class
- Explore the relationship between family size and survival
- Identify patterns and relationships among numerical variables

## Data Cleaning

- Identified missing values
- Filled missing Age values using the median
- Filled missing Embarked values using the mode
- Created a Family_Size feature using SibSp and Parch

## Analysis Performed

- Passenger demographic analysis
- Age and fare distribution
- Fare outlier analysis
- Survival analysis by gender
- Survival analysis by passenger class
- Family size analysis
- Correlation analysis
- Average fare by passenger class

## Key Findings

- Female passengers had higher survival rates than male passengers.
- First-class passengers had better survival outcomes than lower classes.
- First-class passengers paid the highest average fare.
- Fare contained several high-value outliers.

## Tools & Technologies

Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook
